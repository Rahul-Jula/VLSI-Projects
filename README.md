# VLSI Projects

My current hardware portfolio covers RTL microarchitecture, processor design, and ASIC implementation. Start with the repositories below for source code, architecture diagrams, and recorded results.

## Featured projects

- [Programmable Tensor Data-Movement ASIC with Multicast NoC](https://github.com/Rahul-Jula/tensor-data-movement) — descriptor-driven DMA, clock domain crossing, and a 4x4 multicast NoC.
- [GCN Accelerator for Node Classification](https://github.com/Rahul-Jula/gcn-accelerator) — a shared dot-product datapath, sparse graph aggregation, and ASAP7 implementation evidence.
- [Pipelined MIPS Processor](https://github.com/Rahul-Jula/pipelined-mips-processor) — five-stage pipeline, forwarding, custom instructions, and SRAM synthesis.
